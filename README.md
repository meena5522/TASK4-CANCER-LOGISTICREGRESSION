-Task 4 - Classification with Logistic Regression

-Objective

Implement a Logistic Regression model using Scikit-learn to classify breast tumors as Malignant or Benign using the Breast Cancer Wisconsin Dataset.

-Tools Used
Python

Pandas

NumPy

Scikit-learn

Matplotlib

-Steps Performed

Imported the Breast Cancer Wisconsin Dataset

Explored dataset structure and features

Cleaned and preprocessed the data

Removed unnecessary columns

Encoded target labels (Malignant = 1, Benign = 0)

Split data into training and testing sets

Standardized feature values using StandardScaler

Trained a Logistic Regression model

Evaluated model performance using:

Confusion Matrix
* Precision Score
* Recall Score
* Classification Report
* ROC-AUC Score

Visualized the ROC Curve

Performed Threshold Tuning

Visualized the Sigmoid Function

-Dataset

Breast Cancer Wisconsin Dataset
